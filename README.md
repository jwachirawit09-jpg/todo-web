# My to-do list — เอาขึ้น Vercel + เปิดแจ้งเตือน

ในไฟล์ zip มี 7 ไฟล์ ทั้งหมดนี้ต้องอยู่ **โฟลเดอร์เดียวกัน**

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `sw.js` | ตัวช่วยเบื้องหลัง — แจ้งเตือนตอนปิดแอป + ใช้งานออฟไลน์ |
| `manifest.webmanifest` | ทำให้ติดตั้งลงหน้าจอโฮมได้เหมือนแอปจริง |
| `icon-192.png`, `icon-512.png`, `icon-maskable.png` | ไอคอนแอปและไอคอนในแจ้งเตือน |
| `oauth.html` | หน้าเล็ก ๆ ที่รับสิทธิ์จาก Google แล้วเด้งกลับเข้าแอป .apk (เว็บอย่างเดียวไม่ต้องใช้ แต่ทิ้งไว้ไม่เสียหาย) |
| `vercel.json` | ตั้งค่าเล็กน้อยให้ Vercel (ห้าม cache `sw.js`) |

> ถ้าขาด `sw.js` แอปยังใช้ได้ แต่จะเตือนได้เฉพาะตอนเปิดแอปค้างไว้เท่านั้น

## ขั้นที่ 1 — ขึ้น Vercel

### วิธี A — จากมือถือ (ผ่าน GitHub) ✅ แนะนำถ้าตอนนี้อยู่บนมือถือ

1. สมัคร/เข้า **github.com** → **+** มุมขวาบน → **New repository**
   ชื่อ เช่น `todo` → เลือก **Public** → **Create repository**
2. หน้า repo → **Add file → Upload files** → เลือกไฟล์ทั้ง 7 (แตก zip ก่อน) → **Commit changes**
3. เข้า **vercel.com** → **Sign up with GitHub**
4. **Add New… → Project** → เลือก repo `todo` → **Import**
5. หน้า Configure: **ไม่ต้องแตะอะไรเลย** — Framework Preset = *Other*, Build Command / Output Directory ปล่อยว่าง → กด **Deploy**
6. รอ ~30 วินาที จะได้ลิงก์ `https://todo-xxxx.vercel.app` ← **จดไว้ ใช้ในขั้นที่ 2**

### วิธี B — จากคอมพิวเตอร์ (ลากวาง ไม่ต้องมี GitHub)

1. แตก zip ให้ได้โฟลเดอร์ที่มี 7 ไฟล์
2. เข้า **vercel.com/new** → เลื่อนลงหา **Deploy a folder / drag and drop**
3. ลากทั้งโฟลเดอร์ทิ้งลงไป → Deploy → ได้ลิงก์ `.vercel.app` เหมือนกัน

### วิธี C — CLI (ถ้าถนัด terminal)

```bash
npm i -g vercel
cd โฟลเดอร์ที่มี index.html
vercel --prod
```

> **ตั้งชื่อโดเมนให้จำง่าย:** ใน Vercel → โปรเจกต์ → **Settings → Domains** → เพิ่มเช่น `wachirawit-todo.vercel.app` (ฟรี) — ถ้าจะเปลี่ยน ให้เปลี่ยน **ก่อน** ทำขั้นที่ 2 เพราะต้องใช้ที่อยู่เดิมตลอด

## ขั้นที่ 2 — เชื่อม Google Drive + Calendar (ทำครั้งเดียว ~5 นาที)

ข้อมูลจะเก็บในโฟลเดอร์ซ่อนเฉพาะแอปใน Google Drive ของคุณเอง ไม่ผ่าน Claude

1. เปิด **console.cloud.google.com** → **New Project** → ตั้งชื่ออะไรก็ได้
2. **APIs & Services → Library** → เปิดใช้ทั้ง 2 ตัว
   - **Google Drive API**
   - **Google Calendar API**
3. **APIs & Services → OAuth consent screen** → **External** → ใส่ชื่อแอป + อีเมลตัวเอง
   → ในหน้า **Test users** กด **Add users** ใส่อีเมล Gmail ของตัวเอง
4. **APIs & Services → Credentials → Create credentials → OAuth client ID**
   - Application type: **Web application**
   - **Authorized JavaScript origins**
     `https://todo-xxxx.vercel.app`   ← ไม่มี `/` ท้าย
   - **Authorized redirect URIs** (ใส่ทั้ง 2 บรรทัด)
     `https://todo-xxxx.vercel.app/`   ← **มี `/` ท้าย** (สำหรับเวอร์ชันเว็บ)
     `https://todo-xxxx.vercel.app/oauth.html`   ← สำหรับแอป .apk
   - Create → คัดลอก **Client ID**
5. เปิดแอปจากลิงก์ Vercel → เมนู **⋮ → ซิงก์ข้ามเครื่อง (Google Drive)** → วาง Client ID → **เชื่อมต่อ Google** → อนุญาต

> ในแอป .apk ต้องกรอกที่อยู่เว็บนี้ในช่อง **“ที่อยู่เว็บของแอป”** ของหน้าซิงก์ด้วย — Google ไม่ยอมให้ล็อกอินใน WebView
> แอปเลยเปิดเบราว์เซอร์จริงให้ แล้วเด้งกลับผ่าน `oauth.html` (โทเคนไม่ได้ผ่านเซิร์ฟเวอร์ไหนทั้งนั้น เพราะอยู่หลัง `#`)
>
> ถ้าขึ้น `redirect_uri_mismatch` แปลว่าที่อยู่ในข้อ 4 ไม่ตรงเป๊ะ — ต้องตรงทั้งตัวสะกด `https` และ `/` ท้าย
> Vercel สร้างลิงก์ preview ใหม่ทุกครั้งที่แก้โค้ด — ให้ใช้ลิงก์ production (Domains) เท่านั้น ไม่งั้น origin ไม่ตรง

## ขั้นที่ 3 — ติดตั้งลงหน้าจอโฮม + เปิดแจ้งเตือน

1. เปิดลิงก์ในมือถือด้วย **Chrome** (Android) หรือ **Safari** (iPhone)
2. Android: **⋮ → ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก** · iPhone: **แชร์ → เพิ่มไปยังหน้าจอโฮม**
3. **เปิดแอปจากไอคอนบนหน้าจอโฮม** (สำคัญ — แจ้งเตือนเบื้องหลังทำงานเต็มที่เฉพาะตอนเปิดแบบนี้)
4. ในแอป → **⋮ → การแจ้งเตือน** → **เปิดสิทธิ์แจ้งเตือน** → อนุญาต แล้วเปิดสวิตช์ที่ต้องการ:
   - **เตือนงานตามเวลา** — งานที่ตั้งเวลาไว้เด้งตรงเวลา มีปุ่ม *เสร็จแล้ว* / *เลื่อน*
   - **สรุปงานตอนเช้า** — บอกว่าวันนี้มีงานกี่รายการ ค้างเก่ากี่รายการ (ตั้งเวลาเองได้)
   - **การ์ดปักหมุด "เพิ่มงาน"** — ค้างบนแถบแจ้งเตือน กด ＋ เพิ่มงานได้เลย
   - **เลื่อนเตือนครั้งละ** — 5/10/15/30/60 นาที
5. กด **ทดลองแจ้งเตือน** เพื่อเช็กว่ามาจริง

**Android เพิ่มอีกนิด:** ตั้งค่า → แอป → Chrome (หรือ To-do) → แบตเตอรี่ → เลือก **ไม่จำกัด/Unrestricted** ไม่งั้นระบบอาจหน่วงการเตือน

> iPhone: ต้อง iOS 16.4 ขึ้นไป และ **ต้องเพิ่มลงหน้าจอโฮมก่อน** ถึงจะขออนุญาตแจ้งเตือนได้ · การเตือนล่วงหน้าแบบตรงเป๊ะตอนปิดแอปยังทำได้ไม่ดีเท่า Android — ถ้าเป็นงานสำคัญให้กด *เพิ่มลง Google Calendar* ในหน้ารายละเอียดงานควบคู่ไปด้วย
