เก็บข้อมูลไว้ใน Google Drive ของคุณเอง (โฟลเดอร์ซ่อนเฉพาะแอป) ซิงก์ทุกเครื่องที่ล็อกอิน Google เดียวกัน สำรองอัตโนมัติวันละครั้ง เก็บย้อนหลัง 7 วัน — ไม่ผ่าน Claude

Google OAuth Client ID
ที่อยู่เว็บของแอป (แอปในเครื่องต้องใช้)
Google ไม่ยอมให้ล็อกอินในแอปโดยตรง แอปจะเปิดเบราว์เซอร์ให้แทน แล้วเด้งกลับมาเอง — ใส่ที่อยู่เว็บเวอร์ชัน Vercel/GitHub Pages ของคุณ และเพิ่ม <ที่อยู่เว็บ>/oauth.html ใน Authorized redirect URIs ด้วย
วิธีตั้งค่าครั้งแรก (ทำครั้งเดียว ~5 นาที)
  1. อัปโหลดไฟล์แอปขึ้นเว็บของคุณเอง เช่น GitHub Pages (ฟรี) แล้วจดที่อยู่เว็บไว้
  2. เปิด console.cloud.google.com → สร้างโปรเจกต์ใหม่
  3. เมนู APIs & Services → Library → เปิดใช้ Google Drive API และ Google Calendar API
  4. OAuth consent screen → External → ใส่ชื่อแอปกับอีเมลตัวเอง → เพิ่มอีเมลตัวเองใน Test users
  5. Credentials → Create credentials → OAuth client ID → Web application → ช่อง Authorized JavaScript origins และ Authorized redirect URIs ใส่ที่อยู่เว็บของคุณ (เช่น https://ชื่อคุณ.github.io/todo/ สำหรับ redirect URI ให้ใส่ทั้งหน้า)
  6. ถ้าใช้แอป .apk ด้วย ให้เพิ่ม <ที่อยู่เว็บ>/oauth.html ใน Authorized redirect URIs อีกหนึ่งบรรทัด แล้วใส่ที่อยู่เว็บในช่อง “ที่อยู่เว็บของแอป” ข้างบน
  7. คัดลอก Client ID มาวางในช่องด้านบน แล้วกดเชื่อมต่อ
